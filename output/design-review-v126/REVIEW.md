# 승인 전 설계안 - 게임 미적용

일반전: 6인 96×108m, 8인 120×120m, 16인 240×240m, 32인 360×360m.
설치/해체: 8인 128×160m (기존 가로·세로 2배), 12인 228×276m (각 3배).
32번 연습장도 240×240m 확장안 포함. 일반전 사각형 외곽은 01 항구 (32인), 03 제철소 (16인), 09 정비 공장 (6인), 14 물류 창고 (8인), 설치/해체 26 용광로 (12인)만 남기는 안. 인원 규모별 한 개씩이며 연습장은 별도.

현재 자료는 평면 구조·주요 방·진입로·상하층 연결 위치를 검토하는 개념 설계입니다. 모든 지상 통로의 도형 연결은 확인했지만 실제 캐릭터 통과, 시야, 문·엄폐 배치, 경기 균형, 성능은 아직 검증하지 않았습니다. 상층·지하는 위치 관계를 보이는 연결 계획입니다. 확정 후 높이에 맞는 계단 길이와 경사로를 실제로 설계하고 검증합니다.

큰 맵은 중앙까지 이동 시간이 늘어날 수 있습니다. 일반전은 안전한 전진 리스폰 후보로 복귀 시간을 조절하고, 설치/해체는 스폰-사이트 및 A-B 실제 이동시간을 검증합니다. 맵 크기만 보고 균형이 맞다고 보지 않습니다. Web은 미리 생성한 평면도와 정적 벽 청크를 사용하며 동적 조명·물리 소품 수를 면적에 비례해 늘리지 않습니다.

## 통로 폭
일반전 주 통로: 6인 7.5m / 8인 9m / 16인 12m / 32인 16m. 설치/해체: 8인 9m / 12인 11m. 보조 통로 5.4m. 방 입구 일부는 더 좁을 수 있으나 기본 이동로는 위 폭을 유지. 넓어진 통로의 장거리 사선은 코너와 엄폐 배치로 차단.

## UI 배치
장비 창 제목 오른쪽 맵 보기. 방 만들기·봇 전투 맵 선택 바로 아래 맵 보기. 무작위는 후보 목록. Tab 기록은 왼쪽 유지, 평면도는 오른쪽; 좁으면 기록 아래. ESC 게임 메뉴는 병과·장비 아래 현재 맵 카드. 적용/돌아가기 등 같은 줄의 주요 버튼은 동일 크기. 닫기는 지하 탭 바로 옆. 확대창은 층 선택, 휠/핀치 확대, 드래그, 원래 크기, 닫기/ESC. 인터넷 경기에서는 메뉴를 열어도 경기 시간이 멈추지 않습니다. 적 위치를 알려주지 않는 정적 평면도입니다.

## 메뉴명 변경안
- 일시 메뉴 → 게임 메뉴
- 오퍼레이터 · 장비 → 병과 · 장비
- 봇 연습 설정 → 봇 전투 설정
- 이 설정으로 방 만들기 → 방 만들기
- 선택한 장비로 연습 시작 → 봇 전투 시작
- 다음 부활에 적용 예약 → 다음 부활부터 적용
- 기록으로 균형 편성 → 성적 기준 팀 균형
- ESC 설정 → ESC 게임 메뉴
