# Internal N Crush 1.0.4

- 캐릭터 얼굴·몸을 CC0 MakeHuman 기반의 연속 인체 메시로 교체했습니다. 눈꺼풀·코·입술·귀·턱과 팔다리 윤곽을 기존 뼈대에 맞추고, 피부와 직물 재질을 구분했습니다. 여성 두 명·병과별 키·왼손/오른손 설정을 유지합니다. 원거리 모델 LOD와 미리 구운 스키닝도 적용했습니다.
- 1인칭 손바닥·손목·팔과 관절이 이어지는 손가락을 다시 만들었습니다. 손가락이 뒤로 꺾이지 않도록 제한하고 양손 그립·재장전·방아쇠 움직임을 조정했습니다.
- 마지막 탄환을 따라가는 킬캠은 피해자 앞에서 멈춥니다. 마지막 피격 부위의 힘과 관절 래그돌로 평지에서 대략 1–3m 밀려나는 장면을 보여주고, 이어 공격자의 닉네임과 확대 화면을 표시합니다. 지형·충돌에 따라 이동 거리는 달라집니다.
- 저격/지정사수 다섯 종의 피해와 발사 간격을 낮췄습니다. MONOLITH의 몸통 피해는 105→98, ECHO는 55→46/간격 0.68→0.85초입니다. 무게·휴대성·안정성에 따라 끊어 쏘기 회복이 빨라지고 봇은 상황·난이도별로 정지/이동 사격과 반동 제어를 섞습니다.
- HUD 기본 크기를 80%, 배경 농도를 38%로 줄였습니다. 탄약은 탄환 아이콘, 소모분은 빈 실루엣, 예비분은 작은 탄창으로 표시합니다. 무기·오퍼레이터·탄약을 가운데 정렬하고 팀 색상, 전술적인 글꼴, B ‘병과/장비’ 표기를 적용했습니다. 장비 창에는 경기 HUD가 겹치지 않습니다.
- 포탑의 총열·탄약함·구동부·센서와 설치 엄폐물의 발·표시등·팀 색상을 보강했습니다.
- 메인 메뉴에 플레이(내부망 로비/인터넷 로비), 연습(봇 전투/연습장)을 바로 배치했습니다. 같은 실제 봇 배경 위에 반투명 메뉴가 뜹니다. 내부망 목록을 넓히고 IP/비밀번호 창을 분리했습니다. 시작/돌아가기 버튼을 고정하고 필요한 화면에 이동 확인을 넣었습니다.
- 전체 화면에서도 선택 모니터 이하의 게임 해상도를 고를 수 있습니다. MSAA 2×/4×/8×, 그림자·장식 품질, FPS 제한과 HUD 크기/투명도 미리보기를 추가했습니다. 연막·폭발 등 전투 정보는 저사양에서도 유지됩니다.
- Windows 통신 허용 판단을 실행 초기에 요청합니다. 허용 저장은 Windows가 관리하며 경로나 보안 정책 변경 시 재요청될 수 있습니다.
- 공통 소스를 `games/relaystrike/`에서 `game/`로 정리했습니다. Windows 진입점은 `windows/`, Docker Linux/NAS는 `nas/`, 로비 구현은 `services/matchmaker/`입니다.

ZIP 전체를 풀고 실행하세요. 참가자와 서버 모두 1.0.4가 필요합니다. [플레이 가이드](https://github.com/Nukcanon/InternalNCrush/blob/main/game/README.md), [검증 기록](https://github.com/Nukcanon/InternalNCrush/blob/main/game/docs/TEST_REPORT.md), [NAS 운영](https://github.com/Nukcanon/InternalNCrush/tree/main/nas).

사람 경쟁전 승률, 실제 외부 PC/NAS와 저사양/장시간 32인 검증은 남아 있습니다. 현재 모션은 절차적 애니메이션·관절 물리이며 모션캡처나 AAA 품질 인증을 뜻하지 않습니다.
