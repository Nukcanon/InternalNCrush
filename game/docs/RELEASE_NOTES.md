# Internal N Crush 1.1.0

- Windows와 함께 브라우저에서 실행하는 Web 빌드. 스마트폰/태블릿 가로 화면에는 이동·조준·발사·재장전·스킬·가젯·장비 전환 터치 버튼이 표시됩니다. PC는 기존 키보드/마우스를 사용합니다.
- NAS/Linux는 방 목록과 연결 신호만 처리하고 방장 PC/브라우저가 경기를 계산하는 WebRTC 방식. Docker 설정 CMD, 무료 Cloudflare Workers 배포 구성, 방 이름/모드/인원/핑 검색과 정렬을 추가했습니다.
- 메뉴 글씨를 화면 원본 해상도로 렌더링하고 3D 해상도만 별도로 조절합니다. 공통 고정 버튼, 더 작은 반투명 메뉴, 연습장 진입 확인, 기본 꺼짐인 유혈 효과 설정을 적용했습니다.
- 걷기/달리기 속도를 낮추고, 연습장 계단 옆면에 걸리는 봇 경로를 수정했습니다. 레그돌의 총기·장구류·자기 충돌을 분리했습니다.
- CC0 인체 피부 텍스처와 새 직물·가죽·머리카락 미세 표면, 어깨 기울기·모자·손목/팔과 탄창별 재장전, 총기 후면을 다듬었습니다. 모델 관절에 맞춘 피격 볼륨을 사용합니다.
- 회전된 면을 포함한 불투명 공면 겹침을 제거하고 그림자 단계 전환을 부드럽게 했습니다.

브라우저 LAN은 Windows UDP 방과 구분되는 웹 호환 로비를 사용합니다. 같은 방 목록 서버에 연결해야 하며 일부 NAT에서는 별도 TURN이 필요합니다. Cloudflare 구성은 계정에서 배포 후 실제 HTTPS 주소를 입력해야 합니다. 물리 모바일 기기·외부 WAN·ARM NAS와 대규모 경쟁전은 별도 실측이 필요합니다. 검증 및 게시 상태는 PUBLICATION_STATUS.json을 확인하세요.
