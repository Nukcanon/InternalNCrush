# Internal N Crush 1.1.4 검증 기록

## 변경 범위

- 포탑 투시의 자기 가림 판정을 개별 부품에서 회전하는 전체 조립체 경계로 변경했습니다. 소유자 전용 처리를 유지합니다.
- 새 포탑과 교체 포탑의 최초 업그레이드 가능 시각을 설치 후 35초로 설정했습니다. 후속 업그레이드는 기존 18초 간격입니다.
- 교체로 철거되는 이전 포탑에 기존 파괴 효과와 소리를 재생합니다. 추가 폭발 피해는 발생하지 않습니다.
- 권총의 보조 손 위치·방향과 탄창 이동 경로를 수정하고, 재장전 종류에 맞지 않는 공통 마무리 동작을 제거했습니다.
- 일반 가늠자·가늠쇠를 얇게 만들었습니다. 확대 조준의 화면 조준선은 기존 1픽셀 표현을 유지합니다.
- 얼굴 전용 표면을 무광 색상 표현으로 변경했습니다. 몸의 피부·의상 표면은 유지합니다.
- Godot 에셋 가져오기 중 발생한 병렬 처리 크래시를 피하도록 공통 프로젝트의 가져오기를 순차 처리합니다.
- 게임과 NAS/Python/Cloudflare 디렉터리 설정을 1.1.4로 맞췄습니다.

## 재현 및 검사

로컬 Godot 4.4.1에서 27개 기능 검사 모음의 3,722개 단언이 통과했습니다. 신규 포탑 교체 검사 12개와 회전 조립체 경계 검사 129개를 포함합니다. 초기 로컬 맵 준비가 검사와 겹치며 손상된 캐시는 순차 재생성했고 영향받은 검사들을 다시 통과시켰습니다.

GitHub Linux 그래픽 환경에서 412개 프레임을 생성했습니다. 25종 무기의 기본 파지, 조준 형상, 재장전 구간 및 측면 구간, 6개 얼굴, 포탑 가림 상태를 포함합니다. 66ac4c869a5b14b195673be5e8c95c07a5f1be3b 이후 게임 렌더링 코드는 동일합니다.

Windows EXE 검사는 Windows 러너에서 headless로 실행했습니다. 실제 Windows GPU 화면 검사를 의미하지 않습니다. 그래픽 확인은 Linux 렌더링 및 Chromium 이미지로 수행했습니다.

배포 전 웹 연습장 자동 실행 시도는 사용자 인자 구분자가 빠져 메뉴를 다시 촬영했습니다. 따라서 이 결과를 연습장 통과 증거로 사용하지 않습니다. 공개 사이트의 실제 연습장 버튼과 입장 확인창을 누르는 별도 검사로 보완했습니다. 최초 UI 검사는 확인창까지만 진입해 실패했고 확인 버튼 단계를 추가했습니다. 게임 코드나 배포 파일은 바꾸지 않았습니다. 최종 공개 확인 결과는 아래에 기록합니다.

## 확인 범위의 한계

- 이미지 확인은 샘플 프레임과 카메라 각도에 대한 확인이며, 모든 가능한 손/무기 교차 상황을 증명하지 않습니다.
- 포탑 조립체의 보수적인 경계와 벽이 서로 겹치는 배치에서는 일부 투시가 억제될 수 있습니다.
- 실제 저사양 GPU, 휴대폰·태블릿 및 iOS Safari, 외부 NAT/TURN 환경과 장시간 다인 플레이는 이번 검사에 포함하지 않았습니다.
- 공개 인터넷 로비는 별도 운영자 배포가 필요합니다. 기존 NAS 운영자는 1.1.4 서버 패키지로 업데이트해야 합니다.

## 공개 배포 확인

- [1.1.4 릴리스](https://github.com/Nukcanon/InternalNCrush/releases/tag/internal-n-crush-v1.1.4)는 검증한 소스 커밋에 고정되었습니다.
- 사이트 커밋: `9970d05b091d1a6dc6bb1547b470c33725e44894`. [Pages 실행](https://github.com/Nukcanon/nukcanon/actions/runs/36096028101) 성공.
- [공개 파일·UI 검사](https://github.com/Nukcanon/InternalNCrush/actions/runs/36096319950) 성공: 웹 19파일, 67,403,873바이트를 manifest와 대조했습니다. Windows/Web/NAS ZIP을 익명 다운로드해 SHA256SUMS와 일치함을 확인했습니다.
- 공개 메뉴에서 연습장 버튼과 입장 확인 버튼을 눌러 FIELD ACADEMY, 1인칭 무기, HUD가 표시된 화면을 확인했습니다. 페이지 오류 및 Godot 스크립트 오류는 없었습니다.
- Chromium은 SwiftShader 소프트웨어 렌더러를 사용했습니다. 캡처 시 ReadPixels GPU stall 경고와 낮은 FPS가 관측되어, 이 검사는 실행·화면 확인이며 실제 GPU 성능 측정으로 사용할 수 없습니다.
