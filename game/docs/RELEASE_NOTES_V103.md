# Internal N Crush 1.0.3

- 31개 대전 전장과 4개 높이의 야외 FIELD ACADEMY. 고정·이동·방호·회복 표적, 4초 리스폰, 보급 구역과 즉시 장비 변경을 제공합니다. 메인 메뉴의 연습에서 사격장과 봇 연습을 고릅니다.
- 각 인원 규모에 직사각형/정사각형 외곽 두 개를 유지하면서 기존 전장의 층·실내외·우회로를 개편했습니다. 설치·해체 전용 8인 6개, 12인 6개 전장을 추가했습니다. 겹친 평면 정리, 연속된 대각 벽, 텍스처 밉맵과 그림자 자기 겹침을 보정했습니다.
- 짝수 방 정원과 맵 규모를 따로 선택합니다. 기본 8명·8인 무작위·무한 경기, 같은 규모의 무작위 순환, 양 진영 진행 후 순환을 지원합니다. 설치·해체는 최대 12명, 준비 30/45/60초 동안 공격팀 출발 제한·피해 차단을 적용합니다.
- 연속된 몸통/팔다리 표면, 15본 GPU 변형, 곡면 얼굴과 총몸, 발 접지·관성·달리기 팔 스윙을 개선했습니다. 가까운 캐릭터는 관절 스프링 물리, 사망은 피격 충격과 중력을 받는 관절 래그돌을 사용합니다.
- 총구에서 몸으로 흐르는 회복 리본/파동, 연기·불꽃·파편 폭발, 육체 피격 혈흔과 바닥/벽 자국을 추가했습니다. 청록색 상호작용 문은 가까이에서 E 안내를 표시하며 서버에서 개폐를 동기화합니다.
- 25개 총기의 고유 반동 폭·진행 시간, 이동 속도에 비례하는 퍼짐과 끊어 쏘기 회복을 조정했습니다. 능력치 그래프에 발사 DPS/재장전 포함 DPS를 추가하고 스킬·가젯의 사거리·지속·쿨타임을 재조정했습니다.
- 장비 카드 배경을 투명하게 맞추고 체력·탄약·무기명·단축키 정렬을 정돈했습니다. Windows 안내와 빌드 스크립트는 windows/, Docker Linux/NAS 구성은 nas/로 구분했습니다.

ZIP을 모두 풀어 InternalNCrush.exe를 실행하세요. 참가자와 서버는 모두 1.0.3을 사용해야 합니다. [플레이 가이드](https://github.com/Nukcanon/InternalNCrush/blob/main/games/relaystrike/README.md), [NAS 설치](https://github.com/Nukcanon/InternalNCrush/tree/main/nas), [검증 및 한계](https://github.com/Nukcanon/InternalNCrush/blob/main/games/relaystrike/docs/TEST_REPORT.md).

절차적 아트·모션과 자동 밸런스 검사는 수작업 AAA 에셋이나 실제 경쟁전 승률 검증을 대신하지 않습니다. 실제 NAS/외부 다중 PC·저사양·장시간 32인 검증과 계정/MMR/강화 안티치트는 남은 과제입니다.
