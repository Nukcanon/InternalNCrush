## 아트·맵·웹

여성 어깨 관절을7cm 높이고 몸통 쇄골/삼각근 연결을 함께 수정했으며 보이는 리그와 피격용 리그의 위치 일치를 검사했다. 미리보기 썸네일을 갱신했다. 조명 배치가 계단·상층 바닥과 교차하는 후보는 제외하고 캐시115로32개 맵을 다시 생성했다. 장식물 배치의 구조물 여유 공간도 넓혔다. 모든 가능한 맵/시점의 겹침을 제거했다고 단정하지 않는다.

웹 모델의 삼각형 인덱스 합계: 오퍼레이터1,613,712→97,728, 전체 맵9,848,700→3,609,489. 텍스처 최대256px, 단순 재질, 광원/그림자/AA 비활성. 웹과 원본32맵의 충돌 서명32/32 일치. 3D는별도 저해상도 렌더 타깃(PC최대540높이/터치432높이, 느리면288까지), UI는원래 해상도로 렌더링한다. 실제 공유월드 타깃813×540 및 UI1024×680에서 정상 렌더 확인. 메뉴봇 배경도낮은 해상도/15FPS를 사용한다.

IAB1280×720,7봇+로컬 공병 전투에서57FPS 표본, 해당 실행 오류/경고 로그없음. 이PC는RTX4080SUPER이며GTX960·내장GPU·실제 휴대폰 결과가 아니다. 최초전투 로딩 순간1FPS표본과 기존 종료시OpenGL텍스처 경고가 남아 있다. FPS 평균/최저 보장은 하지 않는다. 터치입력은 두손가락 상대좌표 오류회귀로 확인했고 실제 휴대폰 제스처는 미검증.
