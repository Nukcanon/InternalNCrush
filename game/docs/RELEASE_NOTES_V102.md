# Internal N Crush 1.0.2

- 총기별 거리 감쇠·머리/몸통/다리 배율, 연사 속도·탄창·재장전·조준 속도·조준 이동을 재조정했습니다. 저격의 빠른 연사와 샷건의 지나친 원거리 효율을 줄였습니다. 총구가 엄폐물에 막혀 있으면 시선이 보이는 목표도 맞힐 수 없습니다.
- 무기/가젯/방어구/스킬 능력치를 막대 그래프와 거리별 피해 곡선으로 표시합니다. HUD의 키캡과 병과 아이콘, 원형 스킬 쿨타임을 추가했습니다.
- 맵의 겹친 축 정렬 바닥·벽면을 병합 전 잘라내고 반복 면을 제거했습니다. 깊이 정밀도와 표면 무늬의 원거리 앨리어싱도 조정했습니다.
- 19개 맵에 시야 차단 엄폐와 우회 공간을 보강했습니다. 6개 실내·5개 야간 구성, 실제 천장·외벽·조명기구, 작은 16인 다층 전장과 추가 현장 소품을 적용했습니다. 방 생성은 기본 8인이며 정원이 맵 한도를 넘지 못합니다.
- 총구→몸으로 흐르는 회복 광선, 수류탄/포탑 파괴의 폭발·연기·파편·광원, 상태 효과와 연막 표현을 개선했습니다. 돌격은 보호판 대신 파편 수류탄을 고를 수 있습니다. G/가젯 사격을 누르면 준비하고 놓으면 투척하며 3초 지연, 과도하게 들면 자폭 피해가 있습니다.
- 가속·제동·회전 관성과 상하체의 반대 지연, 달리기 팔 스윙을 개선했습니다. Shift 두 번으로 지상 이동 중 슬라이딩할 수 있습니다. 사망은 관절 물리로 낙하하고 피격 방향으로 밀려 지면에 정착합니다.
- 카툰 조명과 재질별 거칠기/금속성, 미세 질감, 그림자와 주야간 광원을 조정하고 원본 모델 카드 52개를 다시 렌더링했습니다.
- Docker Linux/NAS 로비 서버를 추가했습니다. 방 목록·방 생성·모드 선택/생략 매칭, 서버 권한형 게임, HTTPS/WSS, 서명된 단기 입장권과 입력 검증을 제공합니다. 운영할 서버 URL은 별도로 마련해야 합니다.

ZIP을 모두 풀어 `InternalNCrush.exe`를 실행하세요. 참가자와 서버는 **1.0.2**를 사용해야 합니다. [플레이 가이드](../README.md), [Docker 서버](../../../services/matchmaker/README.md), [수치/설계 근거](BALANCE_NOTES.md), [실제 검증 결과](TEST_REPORT.md).

제한: 암호화/서버 검증은 에임봇·클라이언트 메모리 분석까지 완전히 막는 안티치트가 아닙니다. 공개 게스트 매칭은 계정/MMR 서비스가 아닙니다. WSS의 TCP 지연 특성, 외부 32인 장시간 성능, 실제 여러 PC와 NAS ARM64는 별도 검증이 필요합니다. 절차적 아트/모션과 경쟁 밸런스는 계속 다듬을 대상이며 일부 Godot Compatibility 종료에서 텍스처 정리 경고가 남습니다.
