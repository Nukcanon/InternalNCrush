# 1.1.0 검증 기록

2026-09-24. Windows, Godot 4.4.1, RTX 4080 SUPER. 실제 게시 버전·소스 커밋·CI·파일 해시는 루트 PUBLICATION_STATUS.json을 기준으로 확인한다. 이전 공개판 검증 기록은 TEST_REPORT_V104.md에 보존했다.

## 게임·모델·접속 회귀

기존 검사에 V11 663개를 추가했다. 관절별 피격·인체 메시·재질·래그돌 충돌 분리·실제 이동 속도·UI 원본 해상도·회전 공면 제거·광원 상한·WebRTC 입력 경로를 검사한다. V11 중 324개는 27개 무기의 양손과 여섯 재장전 시점에서 서버용 손/총 소켓과 표시 모델 소켓을 비교한다. V07 관성 검사는 좌우 반전된 캐릭터의 로컬 좌표를 직접 비교하던 오류를 수정하고, 양손 × 세 방향에서 월드 가속도의 반대쪽으로 제한된 관성이 생기는지 검사한다.

32개 맵의 정적 지형은 미리 정리해 압축 장면으로 저장하고 저장 전후 충돌 형태·위치·축·레이어의 서명을 비교했다. 큰 맵의 공면 정리가 접속 제한 시간을 넘기던 문제를 해결했다. 로컬 맵0 로딩 표본은 20.7초에서 약 0.4초로 줄었다. 수신 전용 headless 클라이언트의 중복 인체 관절 계산도 제거했다. 32명 독립 참가자는 마지막 참가 후 모두 최신 전체 상태를 받아야 통과한다.

한 차례 Linux CI(35969728962)에서 참가자 27이 31명 상태 수신 이후 연결을 잃었다. 당시 로그만으로 원인을 확정하지 못했다. 이후 각 참가자의 전체 로그와 종료 사유를 보존하도록 보강했고, CPU 두 코어로 제한한 Windows 32개 클라이언트와 다음 Linux CI의 32명 검사는 통과했다. 추가로 32명 접속 후 30초를 더 유지하는 로컬 검사를 세 차례 반복해 모두 통과했다(각 110.0/109.1/107.9초). 이 간헐 현상은 장시간 접속 검사에서 계속 추적해야 한다.

계단 옆에서 서로 다른 높이의 경로점으로 직접 접근하던 봇 경로를 수정했다. 연습장 네 높이를 포함한 실제 수직 이동 검사 14개를 통과했다. 정지한 캐릭터의 충돌 보정이 발걸음으로 계산되던 문제도 수정했다.

로컬 최종 런타임에서는 재장전·부활·피격 기록, 8명 재접속과 서버 재시작, 물체·문의 기존/늦은 참가 동기화, 공수 교대 뒤 맵 순환, 실제 WebRTC 호스트/참가 검사를 통과했다. Windows 방장→브라우저 참가(3ms 표본), 브라우저 방장→Windows 참가(17ms·282개 상태 수신)를 실제 실행했다. 이는 같은 PC의 로컬 연결 결과이며 외부 WAN 결과가 아니다.

## 터치와 브라우저

터치 회귀 20개: 이동·달리기·조준·사격 동시 입력, 한 손가락만 떼기, 반자동 발사 순번, 조준/앉기 토글, 실제 재장전, 기록 보기, 무기 타일 전환, 메뉴 진입 시 눌림 해제, 터치 환경에서 마우스 고정 요청 금지, 연습장 확인 문구, 앱/창 포커스 상실 시 입력 초기화. 포커스 상실 검사는 수정 전 18개 통과·2개 실패, 수정 후 20/20 통과를 확인했다. 가상 스틱과 장비 버튼의 실제 렌더도 확인했다. 추가로 844×390 가로 창에서 같은 18개 입력 검사를 통과하고 메인 메뉴·HUD·일시 메뉴의 버튼 잘림과 배치를 확인했다. PC는 터치 오버레이를 생성하지 않는다.

단일 스레드 WebGL2 출력이며 각 파일은 GitHub의 100MiB 제한보다 작다. 데스크톱 브라우저에서 메뉴→연습장 확인→실제 전장 실행을 확인했다. 포인터 고정은 클릭 콜백에서 요청한다. 내장 Chromium이 고정을 거부하는 경우에는 클릭 사격과 마우스 드래그 조준으로 동작하며, 해당 대체 동작의 실제 시점 회전과 탄 소비를 확인했다. 모바일 페이지의 390×844 반응형 배치는 확인했지만 실제 휴대폰의 GPU·발열·배터리·iOS Safari는 측정하지 않았다.

## Windows 표시와 물리

모니터 두 대 × 세 창 모드에서 낮춘 게임 해상도를 확인했고 UI는 원본 픽셀 해상도를 유지한다. 얼굴/전신과 양손·재장전·장비·HUD·포탑·킬캠을 렌더링해 확인했다. 킬캠 시작 표본 253μs이며 피해자 앞 거리 제한과 0.5초 물리 비행을 유지한다. 사망 시체는 월드 충돌만 사용하고 자기·총·장구류와 충돌하지 않으며 안정 후 정지한다.

로컬 내보내기 ZIP(f7562e7)을 직접 풀어 연습장, 봇 전투, headless 방장/그래픽 참가자, 창을 띄운 방장/그래픽 참가자 네 실행 모두 종료 코드 0을 확인했다. 실제 배포 CI ZIP 결과는 아래 게시 검증에 기록한다. 사용자 실행 게임은 종료하지 않았으며 별도 포트 33888과 검사가 만든 프로세스만 사용했다.

실제 CI 배포 EXE/PCK로도 WebRTC 호스트/참가 검사를 실행해 양쪽 연결과 57개 상태 수신(7ms 표본)을 확인했다. `windows/verify_webrtc.py`는 외부 검사 스크립트를 사용하되 게임 코드는 명시한 배포 PCK에서 읽는다. 소스 프로젝트 실행과 별개의 검증이다.

## NAS·무료 호스팅 구성

최종 소스의 Docker/Worker CI 35971973484 통과. Python API와 NAS 설정 검사 10개, 실제 Linux Compose의 인증서 검증 HTTPS/WSS, 잘못된 CA·호스트명 거부, 내부 API 비공개, Worker 공식 런타임의 HTTP/WebSocket 계약을 확인했다. NAS는 방 정보와 연결 신호만 처리하고 게임 프로세스를 실행하지 않는다.

공개 NAS ZIP에는 운영자 .env가 없고 .env.example만 있다. Windows에서 만든 ZIP 안의 .sh는 LF 줄바꿈인지 검사한다. 설정 CMD는 사용자가 입력한 구성으로 별도의 운영자 업로드 ZIP을 만들며, 기존 설정 백업과 TURN 값 보존을 검사했다. Cloudflare 계정 인증이 없어 실제 공용 서버는 배포하지 않았고 기본 로비 주소도 비워 두었다.

## 성능 표본과 남은 검증

RTX 4080 SUPER, 1280×720, 약 12초의 고정 시점 표본(3cfcc15): 8명 평균 3.21ms / 95백분위 5.91ms / 최대 141.85ms, 32명 평균 9.10ms / 95백분위 13.90ms / 최대 111.32ms. 모바일·저사양·장시간 성능 보증이 아니다. 초기 프레임 급증과 Compatibility 종료 시 소수 GL texture 349524 bytes 경고가 남아 있다.

실제 휴대폰·태블릿, 다중 PC LAN/WAN, NAS ARM64, 저사양과 장시간 32인 경기, 사람 경쟁전 승률, 새 Windows 설치의 최초 방화벽 창은 미확인이다. 입력 권한·암호화·속도 제한은 상용 안티치트나 변조 방장 방지 전체를 대신하지 않는다. 아트 및 모션에 대한 주관적 품질 평가도 별도로 필요하다.
