- API 단위 검사 10/10. CI에서 32명 독립 클라이언트, 재접속·서버 재시작, 물체/문/늦은 참가, 지도 순환, 실제 Linux Docker HTTPS/WSS 검사를 새 소스로 실행한다.
- 실제 Windows UI 46/46: 메인 직접 이동, 같은 봇 배경 유지, 큰 로비 목록과 고정 버튼, 비밀번호/IP 모달·취소·시간 초과·이동 확인, 체크박스 크기 안정성, 낮은 품질의 필수 VFX 유지.
- 실제 모니터 2개 × 창/전체 화면 두 방식 = 6개 검사 통과. 모든 방식에서 선택한 960×540 프레임버퍼를 확인했다. 전체 화면의 OS 출력은 모니터 해상도이며 게임 렌더만 낮아진다.
- 인체 남녀 웨이트 합/본 번호와 메시 변 길이 검사. 손가락이 골반으로 늘어나는 오류를 찾아 수정했다. 실제 얼굴/전신/달리기/공중·착지 래그돌 렌더, 네 총기의 양손·재장전, HUD·장비·포탑·엄폐물·추적 킬캠 캡처 확인.
- 피격 부위 머리/가슴/다리의 평지 사망 물리: 골반 수평 이동 약 2.32/2.32/2.36m, 바닥 충돌·유한 위치 확인. 장애물/경사면에서는 거리 보장 없음. 0.5초 비행 장면 뒤 공격자 화면으로 전환.
- 킬캠 진입 표본 281μs, 기존 전장과 미리 준비한 메시 재사용. 마지막 탄환 카메라 0.1–120m 수학적 거리 검사 및 실제 렌더에서 피해자 앞 최소 1.1m 확보.
- 시작 통신 소켓 열기/닫기 확인. 방화벽 규칙 강제 수정 없음. 새 Windows 설치에서 최초 경고창의 실제 표시 시점은 확인하지 못했다.
