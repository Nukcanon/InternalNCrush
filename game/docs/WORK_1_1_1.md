## 현재
코드 구현과 회귀 검사 진행 중. 검증 없이 완료로 간주하지 않는다.
초기 Windows 기준(기존 높은 품질, RTX4080SUPER 1280×720): 8인 평균3.57ms/P955.95/최대94.1;32인 평균7.52/P9513.03/최대137.6.
렌더러는 NVIDIA OpenGL 실제 GPU다. 이 결과는 사용자 웹11FPS나 내장 GPU의 해결 증거가 아니다.
새 설치 방식 때문에 구형 즉시설치 테스트/봇 행동을 새 입력 계약에 맞추는 중.
