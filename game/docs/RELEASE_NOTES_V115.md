## 그래픽과 메뉴

- 다운로드판의 상세 인체 모델, 장비 금속 재질과 건축물 재질을 기존 1.1.4 소스 기준으로 복원했습니다. 피부는 사진 질감을 쓰지 않는 페인트 표현을 유지합니다.
- 다운로드판의 기본값은 현재 모니터 해상도, 전체화면, 중간 그래픽입니다. 이후 저장한 설정은 유지하며, ‘기본설정으로 복원’으로 초기값을 다시 적용할 수 있습니다.
- 다운로드판 메인 메뉴는 제한된 프레임의 실제 봇 전투를 표시하며 경기를 시작하면 메뉴 전투를 제거합니다.
- 웹판은 별도 경량 모델·재질을 사용합니다. 표면의 시선 각도가 바닥을 검게 만드는 처리를 제거했고, 광원 사용 시에도 최소 밝기를 확보했습니다.
- 웹판 메뉴는 실제 봇 전투에서 촬영한 1920×1080 사진 12장을 무작위 순서로 교차 전환합니다. 동시에 두 장만 메모리에 유지하며 메뉴에서 전투를 시뮬레이션하지 않습니다.
- 두 버전의 1인칭 손을 32%, 팔 두께를 약 43% 늘렸습니다. 무기 전체 크기와 조준 좌표는 유지했습니다.
- 병과별 스킬 도형의 실제 범위로 중앙을 맞췄습니다. 테두리와 아이콘에 얕은 양각 표현을 추가하고 비활성 회색 및 쿨타임 표시를 유지했습니다.
- 탄흔은 어두운 구멍 중심과 깨진 가장자리를 표현합니다. 다운로드판에는 균열과 더 세밀한 질감을 추가했습니다. 충돌 지형을 뚫는 효과는 아닙니다.
