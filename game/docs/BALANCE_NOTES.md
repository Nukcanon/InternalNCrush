# 1.0.4 전투 밸런스

저격/지정사수의 높은 피해와 빠른 연사를 함께 낮추고, 짧게 끊어 쏜 뒤 정확도가 돌아오는 시간을 무기별로 줄였다. [Valve의 회복 설계 설명](https://blog.counter-strike.net/second-shot/)에서 짧은 점사와 장기 연사의 회복을 분리하는 원리를 참고했다. CS2의 현재 무기 수치를 그대로 복사한 값이 아니다.

SCOUT 76 / 1.60초, MONOLITH 98 / 2.35초, ECHO 46 / 0.85초, LARK 32 / 0.48초(14발), KESTREL 44 / 0.78초. MONOLITH도 방어 없는 몸통 한 발로 100 HP를 제거하지 못한다. 무기별 머리 배율·거리 감쇠·ADS 이동 제한은 유지한다.
