# Internal N Crush

Windows tactical FPS built with Godot 4.4.1 Standard and GDScript. LAN play and self-hosted Linux/NAS internet lobbies.

- [Game and Windows download](https://nukcanon.github.io/nukcanon/internal-n-crush.html)
- [Source and build instructions](games/relaystrike/README.md)
- [Releases](https://github.com/Nukcanon/InternalNCrush/releases)
- [Handoff](CODEX_HANDOFF.md)
- [Docker public lobby and security boundaries](services/matchmaker/README.md)

The game source moved from `Nukcanon/nukcanon/games/relaystrike` to this dedicated repository. The public website keeps its existing address.

Generated audio, fonts and models are rebuilt by the documented tools and CI. Original geometry and animation generators, audio source archive, attribution and licenses are included.
