# Internal N Crush 0.7.0

Windows x64용 내부망 FPS입니다. 최대 32명, 6개 병과, 실내·실외 19개 전장과 5가지 모드를 제공합니다. 압축을 풀어 실행하면 됩니다. 외부 인터넷 없이 경기를 진행할 수 있습니다.

## 빠른 시작

1. ZIP을 모두 풀고 `InternalNCrush.exe`를 실행합니다. `.pck`는 exe 옆에 있어야 합니다.
2. 한 PC에서 **방 만들기** → 모드·맵·인원·스킬 등을 선택합니다.
3. 다른 PC는 **내부망 방 찾기 / IP로 접속**을 사용합니다. 검색되지 않으면 방장 화면에 표시된 IP를 직접 입력합니다.
4. 대기실에서 병과·장비를 고르고 방장이 경기를 시작합니다.
5. 혼자 확인하려면 **봇 연습 · 난이도 선택**에서 하/중/상, 봇 수(3/5/7/15/31), 모드와 맵을 선택합니다. 방 만들기에서도 난이도를 선택할 수 있습니다.

Windows 방화벽에서 이 게임의 내부망 통신을 허용해야 합니다. UDP 27888(게임), 27889(방 검색)를 사용합니다. 학교 네트워크에서 PC 간 통신을 차단했다면 관리자에게 해당 연결 가능 여부를 확인해야 합니다. 외부 인터넷에 포트를 공개할 필요는 없습니다.

오른쪽 위에 FPS·서버 왕복 핑을 표시합니다. 방장은 HOST로 표시됩니다.

## 주요 규칙

- 최대 전투 참가자 32명. 전용 서버는 참가 인원에 포함되지 않습니다.
- 개인전, 팀 데스매치, 제한 부활 팀전, 거점 점령, 장치 설치·해체.
- 입장 시 인원에 맞춰 자동 배치하고, 대기실에서는 각자 자기 팀을 선택합니다. 방장은 다른 참가자도 이동시킬 수 있습니다. 경기 중에는 방장만 팀을 변경합니다. 양 팀이 16명씩 찼을 때 방장은 교환할 두 참가자를 지정합니다. 설치/해체 중 팀을 바꾸면 다음 라운드부터 합류합니다. 경기 종료 후 같은 팀/무작위/기록 기반 재편성을 선택할 수 있습니다.
- 병과 사용과 특수 스킬 사용을 따로 선택합니다. 스킬 OFF여도 회복 무기·수리 도구·엄폐물·연막·섬광 등 장비 기능은 유지됩니다.
- 체력 100, 방어구 0/25/50. 기본 방어구는 0입니다. 일반 모드에서 방어구는 장비 창에서 선택하면 무료로 적용합니다. 폭탄 모드는 구매해야 합니다. 방어구가 먼저 소모됩니다.
- 체력 자동 회복은 **기본 OFF**이며 부활 횟수와 별개입니다. 켜면 마지막 사격·피격 후 10초를 기다린 뒤 초당 1 HP만 회복합니다. 메딕은 전투 중에도 훨씬 빠르게 회복시킬 수 있습니다.
- 부활 후 1.5초 동안 피해를 받지 않고, 발사·가젯·스킬을 사용할 수 없습니다. 보호 중 캐릭터 외곽에 빛나는 막을 표시합니다. 부활 위치는 적과 거리·시야·아군 거리를 평가하고 점유된 위치를 피합니다. 팀전은 팀 시작 지역에서, 개인전·점령은 전장 전역에서 후보를 고릅니다.
- 기본 이동 7.4m/s, 달리기 11.2m/s, 앉기 3.1m/s, 정조준 이동 4.4m/s. 빠른 걷기·점프 시 탄 퍼짐 증가. 정조준·앉기는 정확도를 높입니다.
- 얕은 반투명 물은 수면 아래에 맞은 부위, 또는 물에 들어간 사람이 밖을 향해 사격할 때 피해를 50%로 줄입니다. 두 조건이 겹쳐도 25%로 추가 감소하지 않습니다.
- 맵 보급품은 현재 공격 무기의 최대 예비탄 중 25%를 지급하고 30초 후 재생성됩니다. 떨어진 무기에서는 남은 탄약을 회수합니다.
- 무한 탄약 옵션은 공격용 예비탄에만 적용됩니다. 재장전은 필요하며 의료·가젯 자원은 제한됩니다.
- 단순한 붉은 명중 입자와 Dead 밀림 연출. Dead 모델은 6초 내 사라지고 무기는 최대 40초 남습니다.

## 화면과 사운드

- Tab 점수판은 BLUE/ORANGE를 나눠 표시하고, 자기 행을 강조합니다. K/D/A와 목표 점수를 표시합니다. 개인전은 전체 순위로 정렬합니다.
- B 장비 창에서 캐릭터·주무기·보조무기·가젯을 미리 볼 수 있고, 끌어서 회전합니다. 체력·속도·무기 성능·장비 효과·스킬 설명을 함께 표시합니다. 정찰은 저격/지정사수 병과입니다.
- 팀 색을 몸통·팔·다리와 장비에 넓게 적용하고 일부 작은 장식을 줄였습니다. UI와 모델 모서리를 부드럽게 다듬었습니다.
- 저격 스코프 바깥은 검게 가립니다. 사격을 멈추면 누적 오차와 T자 반동이 시간에 따라 회복됩니다. 이동을 멈춰도 십자선이 좁아집니다.
- 25종 공격 무기별 샘플 기반 발사음, 돌/금속/물 표면별 4종 발소리, 명중·재장전·전환·UI 소리. 총소리·발소리는 위치와 거리에 따라 들립니다. 52개 음원에 기계음, 연막·섬광·폭발·전개 효과가 포함됩니다. 출처와 개별 라이선스는 SOUND_CREDITS.md를 참고하세요.
- Dead 동작을 5가지로 분산합니다. 모델은 5.5초 뒤 사라지고, 당시 들고 있던 주무기 또는 보조무기는 실제 모델로 최대 40초 남습니다.

## 연결과 재접속

방 찾기에 들어가면 바로 주변 서버를 검색하고 3초마다 갱신합니다. IP 직접 입력도 가능합니다. 연결 실패나 서버 응답 중단 후에는 게임을 종료하지 않고 최근 서버 재접속 버튼을 사용할 수 있습니다. 동일 플레이어의 이전 연결이 실제로 살아 있으면 새 접속을 거절하며, 응답 없는 이전 연결은 정리합니다. 방에서 나가면 이전 상태 번호와 조각 수신 버퍼도 초기화합니다.

게임 실행 시 최신 버전을 비동기로 확인합니다. 인터넷이 없거나 4초 안에 응답이 없으면 그대로 내부망 플레이를 진행합니다. 새 버전이면 메인 메뉴에 다운로드 안내를 표시하고, 서로 다른 게임 버전끼리 접속할 때는 양쪽 버전을 표시합니다.

닉네임 뒤의 `#01` 같은 번호는 방 안에서 플레이어를 구분하며, 같은 방에 재접속하면 유지됩니다. 방장은 대기실과 경기 중 참가자 관리에서 강퇴할 수 있습니다. 일반 참가자는 대상 외 인원의 60% 이상(최소 2명) 찬성으로 강퇴할 수 있습니다. 투표는 25초, 발의 대기는 60초이며 강퇴된 식별자는 3분간 재참가할 수 없습니다. 봇은 투표권이 없고 방장은 투표 대상에서 제외됩니다.

## 장비 선택과 발사 방식

- B에서 병과·주무기·방어구·가젯을 고르고 **다음 부활에 적용 예약**을 누릅니다. 현재 캐릭터는 바뀌거나 부활하지 않습니다. 다음 부활에 적용됩니다.
- 폭탄 모드에서는 구매 시간에 **구매하기**를 누릅니다. 무기·방어구·가젯 비용과 보유 크레딧을 표시합니다. 전투 중 선택은 다음 라운드 구매 예약이며, 부족한 돈이나 메딕 정원 때문에 적용하지 못하면 메시지로 알립니다.
- 크레딧은 폭탄 모드에서만 사용합니다. 다른 모드는 장비 선택이 무료입니다.
- 1 주무기 / 2 보조무기 / 3 가젯 / 4 통제병의 섬광탄. 장비를 고른 후 클릭합니다. 스킬은 F로 즉시 사용합니다.
- AUTO는 누르고 있는 동안 연발, SEMI는 클릭당 한 발, BURST는 클릭당 3발입니다. TRIAD와 TRIO는 3점사, 저격·지정사수·샷건·일반 권총은 단발입니다.
- 기본 VECTOR-24는 몸통 피해 24, 정밀 명중 배율 1.5입니다. 이전의 머리 높이 자동 추적 봇은 몸통 중심의 오차·반응 지연·점사 간격을 갖도록 변경했습니다.
- 보호판은 손상된 방어구 25를 복구하고, 거치대는 앉아서 사용한 뒤 정지 사격 정확도를 높입니다. 수리 도구는 아군 엄폐물/포탑에 조준하여 사용합니다. 가젯의 조건·효과는 장비 창과 HUD에 표시됩니다.

## 공병

엄폐물: 내구도 250/500/800, 폭탄 모드 가격 300/600/1000. 공병당 동시 2개. 포탑은 공병당 1개, 충전 30초입니다. 기존 포탑 5m 이내에서 조준하고 F를 누르면 강화합니다. 최초 설치 후 3회 강화, 최대 4단계입니다. 파괴 후 재설치하면 1단계이며 충전 시간은 초기화/환불되지 않습니다.

포탑은 공병 엄폐물 위로 포신이 노출되는 높이로 설치됩니다. 벽을 관통하지 않습니다. 탐지 범위는 25/30/35/40m이고 노출된 포탑 상부는 공격할 수 있습니다. 연막은 포탑 시야를 차단하고 섬광은 잠시 작동을 멈춥니다.

## 폭탄 모드 경제

시작 자금 800, 승리 3500, 패배 단계별 1900/3000/3300. 승리 시 패배 보상 단계가 하나 줄어듭니다. 최대 자금 8000. 구매 20초, 전투 150초, 설치 3초, 해체 5초, 설치 후 작동 40초. 3라운드마다 공격·수비를 바꾸고 경제를 초기화합니다. 먼저 7라운드를 이긴 팀이 승리합니다.

## 킬피드와 참가자 식별

화면 오른쪽 위에 공격자 닉네임 → 무기 실루엣 → 상대 닉네임이 표시됩니다. 닉네임 색은 처치 당시 팀 색상이며, 포탑은 설치한 플레이어 이름과 포탑 실루엣을 표시합니다. 같은 닉네임도 방 내부 번호(#01 등)로 구분합니다. 기록은 잠시 표시된 뒤 사라지고, 최신 6개까지 유지됩니다.

## 전투 피드백 (0.7.0)

피격 방향을 빨간 호와 화살표로 표시하며, 화면을 돌려도 실제 공격 방향을 가리킵니다. 표시가 약 1.15초 후 사라지고, 피해를 받은 플레이어에게만 방어구/일반 피격음이 들립니다. 1인칭·3인칭 무기에 발사 반동을 적용하고, 자신의 화면에 회전하는 탄피가 튀어나와 최대 8초 동안 남습니다. 탄피는 최대 72개를 유지합니다.

충돌에는 비유혈 섬광과 작은 먼지 흔적을 사용합니다. 바닥 흔적은 약 4.5초 뒤 사라집니다. 탈락한 캐릭터는 충돌 방향으로 조금 밀리며 앞·뒤·옆으로 넘어지고, 벽 앞에서 멈춘 뒤 정리됩니다.

이동 거리로 발 디딤 주기와 발소리를 맞추고 어깨·상체·총에 반대 방향 흔들림을 더했습니다. 캐릭터별 호흡과 대기 중 자세 변화, 방향 전환 시 총의 관성도 적용합니다. 차분한 의상 위 파랑/주황 보호대와 헬멧, 앞뒤 표식으로 팀을 구분합니다.

## 모델·모션·전장

6개 병과마다 헬멧/후드, 보호판, 배낭, 도구와 색상 표식을 달리했습니다. 캐릭터마다 idle, walk, run, crouch, crouch_walk, jump, fall, fire, reload, hit, land, death 기본 12개와 Dead 5개의 관절 애니메이션이 있습니다. 실제 게임은 이동 애니메이션 위에 상체 조준·발사·재장전·피격을 합성합니다. 1인칭 총은 탄창/펌프/볼트/장전부 등 무기별로 움직이며 전환·달리기·착지 동작이 연결됩니다.

19개 맵을 권장 인원으로 분류합니다: 6인용 6개, 8인용 6개, 16인용 4개, 32인용 3개. 방 만들기와 봇 연습에서 규모를 먼저 고르고 맵을 선택합니다. 권장 규모와 실제 방 최대 인원은 별도 옵션입니다. 실내에는 기계 설비·실험실·기둥·천창을, 실외에는 층이 나뉜 건물·배관·창틀·조명·교량을 추가했습니다. 절차적 표면 질감, 3축 모따기, MSAA 2×를 적용합니다. 기존 항구와 물류 기지에는 통과 가능한 창고 통로, 컨테이너, 상자, 콘크리트 엄폐물, 크레인, 나무와 도로를 배치했습니다. 고정 구조물은 공간별로 묶어 그리기 호출 수를 줄였습니다. 병과 모델 12개(6종 × 2팀)와 장비 27종의 GLB 원본은 소스의 빌드 도구로 생성할 수 있습니다. 실행 ZIP에는 실행에 필요한 파일과 라이선스만 포함합니다. 다른 게임에서 추출한 모델이 아닙니다.

## 봇 행동과 난이도

| 난이도 | 최초 시야 확보 후 반응 | 기본 조준 오차 | 행동 차이 |
|---|---|---|---|
| 하 | 약 0.85초 | 약 3.8도 | 느린 탐색·장비 판단, 반동 보정 없음 |
| 중 | 약 0.45초 | 약 1.8도 | 멈춰 쏘기, 부분 반동 보정, 위험 시 후퇴 |
| 상 | 약 0.22초 | 약 0.65도 | 빠른 판단, 더 강한 반동 보정·목표 대응 |

공통으로 벽과 연막에 가려진 상대는 새로 포착하지 않습니다. 마지막 목격 위치는 잠시 기억합니다. A* 경로는 정적 장애물, 새로 설치한 엄폐물·포탑, 최근 피해 지역을 반영합니다. 막히면 우회 방향을 확인하고 경로를 다시 계산합니다. 거점에 인원을 분산하고, 공격팀은 설치, 수비팀은 해체를 시도합니다. 메딕 회복·공병 수리·통제병 연막/섬광은 스킬 OFF에서도 작동합니다. 상 난이도도 피해량이나 체력 보너스를 받지 않습니다.

## 정확도와 T자 반동

이동 속도·공중 수직 속도·연사 누적에 따라 탄 퍼짐이 증가하고, 멈춤·정조준·앉기 후 줄어듭니다. 긴 연사는 짧은 점사보다 정확도 회복이 늦습니다. 십자선 네 팔은 실제 탄 퍼짐 각도를 카메라 시야각에 투영하여 표시합니다.

연발 무기는 처음에는 위로 올라간 뒤 좌우로 뻗는 자체 T자 패턴을 사용합니다. 탄 퍼짐의 무작위 오차와 반동 패턴은 별개입니다. 벽에 남는 흔적으로 확인할 수 있습니다. Valve가 설명한 이동/공중 정확도와 점사/연사 회복 원리를 참고했으며, CS2의 특정 총기 수치·패턴을 그대로 복제한 구현은 아닙니다.

- Valve: https://blog.counter-strike.net/second-shot/
- Valve: https://blog.counter-strike.net/air-time/

## 현재 검증 범위와 제한

- 핵심 규칙 자동 시험과 같은 실행 환경에서의 다중 ENet 접속 시험을 수행했습니다. `docs/TEST_REPORT.md` 참조.
- 실제 Windows PC 여러 대의 LAN 시험과 구형 내장그래픽 성능 시험은 아직 필요합니다. 특정 내장그래픽에서 32명 60FPS를 보장하지 않습니다.
- 27종 장비의 자체 제작 모델, 관절이 있는 6개 병과 캐릭터와 2팀 색상, 손·팔, 이동·재장전·전환·피격 애니메이션이 포함됩니다. 그래픽·음향은 개발 단계입니다. 상용 게임 수준의 완성된 연출은 아닙니다.
- 봇은 장애물 경로, 점령/설치/해체, 회복/수리, 장비/스킬, 구매를 수행합니다. 체력·탄약·시야·목표·최근 피해에 따라 행동을 고릅니다. 학습 모델을 훈련하거나 플레이 습관을 영구 학습하지는 않습니다.
- 서버 종료 시 방은 종료됩니다. 자동 서버 승계·음성 채팅·인터넷 매칭은 없습니다.
- 봇의 팀 전술과 모델 동작은 추가 다듬기가 필요한 개발 버전입니다. 제한 부활은 개인 목숨/팀 공용 부활을 선택하며, Dead 후 왼쪽 클릭으로 아군 관전 대상을 전환합니다.

## 소스 수정·재빌드

Godot 4.4.1 Standard로 `project.godot`를 엽니다. 무기 수치는 `assets/weapons.json`, 모드·경제 규칙은 `scripts/game.gd`와 `rules.gd`, 맵은 `scripts/arena.gd`와 `scripts/map_layouts.gd`에서 수정합니다. GitHub 소스에서 빌드할 때는 `python tools/prepare_assets.py`를 먼저 실행해 오디오와 OFL 글꼴을 준비합니다. 그 다음 Godot으로 가져오고 `godot --headless --path . --script tools/build_models.gd`로 모델을 생성합니다. 다시 가져온 후 내보냅니다. 배포 ZIP에는 준비된 자산이 포함되어 있습니다.

수정한 모든 클라이언트와 서버는 동일 버전으로 배포하세요. 런타임 설정은 `%APPDATA%/Godot/app_userdata/Internal N Crush/settings.cfg`에 저장됩니다.

```powershell
python games/relaystrike/tools/prepare_assets.py
godot --headless --path games/relaystrike --editor --import --quit
godot --headless --path games/relaystrike --script res://tools/build_models.gd
godot --headless --path games/relaystrike --editor --import --quit
godot --headless --path games/relaystrike --script res://tests/test_v07.gd
python games/relaystrike/tests/run_network_lifecycle.py
godot --path games/relaystrike --script res://tests/windows_display.gd -- --no-save-profile --no-update-check
godot --path games/relaystrike --script res://tests/windows_smoke.gd -- --no-save-profile --no-update-check
```

생성 자산은 Git에서 제외되지만 오디오 원본 ZIP, 생성 코드, 라이선스와 고정 글꼴 체크섬은 저장소에 포함됩니다. 위 준비 절차 없이 게임을 바로 열면 자산이 누락될 수 있습니다.
