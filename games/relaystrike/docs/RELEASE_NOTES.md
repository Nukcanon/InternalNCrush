# Internal N Crush 1.0.0

- 카툰 스타일의 사람형 캐릭터로 다시 모델링했습니다. 얼굴과 손가락, 곡면 팔다리, 천 조끼와 접힌 소매, 병과별 모자·도구·가방을 추가했습니다.
- 돌격 180 / 정찰 172 / 중화기 188 / 공병 176 / 통제 183 / 메딕 170cm. 시점·충돌·머리 판정·킬 리플레이에 키 차이를 반영하고 앉은 자세의 모델과 판정을 맞췄습니다.
- 1인칭 팔·손, 총기 모서리와 금속 재질, 장비의 곡면, 나무의 줄기·가지·수관을 다듬었습니다.
- 19개 맵에 벤치·화분·설비함·분리수거함·팔레트와 자루·파이프·작업대·케이블 릴을 더했습니다. 주요 이동 경로와 스폰은 유지하도록 배치합니다.
- 드럼통·상자·콘·연료통·타이어를 총으로 쏘면 명중 위치와 방향에 따라 밀리거나 회전합니다. 서버가 물리를 계산하고 늦게 참가한 사람에게도 같은 상태를 전달합니다. 봇 회피와 킬 리플레이에도 위치가 반영됩니다.
- 기존 0.7의 관성 모션, 실시간 봇 메뉴, 모니터·해상도 선택, 작은 킬피드, 2.5초 1인칭 + 1초 공격자 확대 리플레이를 포함합니다.

ZIP을 모두 풀고 `InternalNCrush.exe`를 실행하세요. 참가자 모두 **1.0.0**을 사용해야 합니다. 소품은 파괴/폭발하지 않으며 충격 반응은 게임용으로 조정했습니다.

알려진 문제: 일부 Windows 종료에서 Godot Compatibility 텍스처 정리 경고가 로그에 남습니다. 실제 여러 PC의 LAN, 장시간 32인 교전과 저사양 GPU는 추가 검증 대상입니다. 킬 리플레이는 수신 기록 기반 재구성입니다.
