# Internal N Crush 0.7.0

- 8인 접속 검사 종료를 명시적으로 동기화했습니다. 늦게 시작한 참가자, 재접속 및 서버 재시작을 엄격하게 검사합니다.
- 다중 모니터 선택, 창/테두리 없는 전체 화면/독점 전체 화면, 8K·울트라와이드 프리셋과 직접 입력, 15초 자동 복구를 추가했습니다.
- 메인 메뉴는 녹화 영상 대신 분리된 오프라인 6인 봇 전투를 실시간으로 보여 줍니다.
- 움직임에 가속·감속을 넣고, 출발 시 상체 기울기, 급회전·정지 때 하체 관성, 제자리 회전 발 디딤, 달리기 팔 스윙, 점프·착지·앉기 전환을 다시 구성했습니다. 무기 손잡이에 양손 위치를 맞춥니다.
- 캐릭터 장구류·헬멧·장갑, 총기 조작부·레일·총구, 공병 포탑의 구동부·센서·삼각대, 엄폐물을 세분화했습니다. 탄피에 테두리·뇌관·빈 탄구를 넣고 최대 72개, 8초 수명을 적용했습니다.
- 피격음을 둔탁한 저음 충격음으로 교체하고 비조준 사격 반동을 강화했습니다.
- 19개 맵의 경계를 비직사각형으로 바꾸고, COURTYARD·SWITCHBACK·ROOFTOP·MARKET LOOP 4개 전장을 굽은 동선·경사로·고저차로 재설계했습니다.
- 킬피드를 약 1/4 면적으로 줄이고 배경을 반투명하게 했습니다.
- 사망 시 공격자의 1인칭 기록을 약 2.5초 재구성하고, 1초 동안 공격자를 3인칭 확대하며 전용 충격음을 재생합니다. 공격자·무기·정밀 명중 여부를 표시하며 SPACE/ESC로 건너뜁니다. 부활하면 즉시 종료합니다.
- 게임 소스와 릴리스를 전용 공개 저장소 Nukcanon/InternalNCrush로 이전했습니다. 홈페이지 주소는 유지합니다.

ZIP을 모두 풀고 InternalNCrush.exe를 실행하세요. 모든 참가자는 0.7.0을 사용해야 합니다.

킬 리플레이는 수신한 위치·조준·사격 이벤트를 바탕으로 한 재구성이며 영상 녹화가 아닙니다. 네트워크 지연이나 기록 부족은 재생에 반영될 수 있습니다. 환경 피해·자기 자신에 의한 사망은 공격자 리플레이를 만들지 않습니다.

실제 Windows에서 RTX 4080 SUPER, 2560×1440 모니터 2대의 화면 전환과 플레이 실행을 확인했습니다. 서로 다른 PC 사이의 실제 LAN, 장시간 32인 교전, 저사양 GPU는 별도 검증 대상입니다.

알려진 문제: 일부 Windows 봇 전투 실행을 종료할 때 Godot Compatibility 렌더러의 텍스처 정리 경고가 로그에 남습니다. 해당 검사에서 플레이 중 스크립트 오류는 없었고 프로세스는 종료 코드 0으로 끝났지만, 경고의 근본 원인은 아직 해결하지 못했습니다.
