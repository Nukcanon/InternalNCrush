# 1.0.2 검증 기록

## 로컬 기능 검사

1,089/1,089 통과: rules 28, regressions 58, AI/aim 38, bots 6, v04 31, v05 89, killfeed 15, v06 51, v07 35, v1 97, v101 299, 실제 층 이동 9, v102 293, 네트워크 입력/입장권 40.

기존 32인 기본값을 전제로 한 검사는 map0/max32를 명시했습니다. 고정 이동 속도 검사는 의도한 무기별 속도 계수를 확인하도록 갱신했습니다. 경로·스폰 안전성 요구는 유지합니다. 실행 로그: `validation/functional-v102/`.

- 새 회귀 항목: 겹치는 두 바닥의 윗면이 한 번만 렌더되는 면적, 총구 차폐, 거리 감쇠/부위 배율, 저격 재발사, 수류탄 지연·조리·자폭, 지상 슬라이딩/공중 거절, 공중 래그돌 낙하, 실내 천장, 맵 정원 제한.
- API 9개: 세션/버전, 엄격한 타입/정원, 서명/만료/예약, 모드 선택/생략, 내부 자격 증명, 공개 목록 비밀 제외, 크기/빈도, 세션/방 만료, 방장만 종료.
- 로컬 공개 로비: 실제 API가 Godot 방을 띄우고 독립 WebSocket 클라이언트 2개가 입장·경기 시작·탄약 감소·상태 동기화 성공. 이 검사는 루프백 HTTP/WS이며 인터넷 TLS 검사를 대신하지 않습니다.
- Windows RTX 4080 SUPER: 19개 맵, 능력치 그래프, 메딕 총구→몸 회복 파동, 폭발, 달리기/슬라이딩/공중 사망 렌더링 성공. GDScript/셰이더 오류 없음. 일부 종료 텍스처 정리 경고는 남음.
- 면 제거/시야 샘플: `validation/v102-map-audit.json`. 축 정렬 메시의 평면 중복을 검사하며 움직이는 카메라에서 가능한 모든 GPU 아티팩트가 없음을 증명하는 검사는 아닙니다.

## 공개 CI와 배포

최종 Linux 컨테이너/인증서 검증, 32클라이언트와 재접속, 공개 Windows ZIP 재다운로드·EXE 실행, GitHub Pages 바이트 검증 결과를 완료 후 추가합니다. 상태는 저장소 루트 `PUBLICATION_STATUS.json`을 기준으로 확인하세요.

## 검증 범위

단일 Windows PC/CI의 독립 프로세스는 실제 다중 PC 또는 외부 WAN 부하 검사가 아닙니다. 헤드샷은 캡슐 높이 구간이지 본별 충돌이 아닙니다. 절차적 아트와 경쟁 밸런스는 추가 사용자 플레이테스트가 필요합니다. Docker 설치 가능한 ARM64 경로는 포함했지만 실행하지 않은 CPU를 검증 완료로 표시하지 않습니다.
