## 실제 렌더링

Windows NVIDIA RTX 4080 SUPER, Compatibility/OpenGL 3.3. 캐릭터 얼굴·달리기·공중/지상 래그돌, 31개 경쟁 전장의 조망/현장 시점, 연습장 각 층, 메뉴/방 선택/투명 카드/DPS, 회복·폭발·혈흔·문을 렌더링했다. 단계별 수정 전 화면과 최종 화면이 validation/ 아래에 함께 있으므로 이름의 final 로그와 최신 파일을 확인한다. 렌더 프레임 소수만 캡처하는 도구의 화면 FPS는 성능 측정값으로 사용하지 않는다.

바닥 물결무늬는 동일 시점에서 그림자 OFF/절차 노이즈 OFF/바이어스 조절을 비교했다. 그림자를 끄면 사라지고 노이즈를 꺼도 남아 자기 그림자 문제로 분리했다. 태양 shadow_bias .06→.25, normal_bias .9→1.5 이후 동일 시점에서 무늬가 사라지는 것을 확인했다. 겹친 축 정렬 바닥 면적 합집합 검사와 새 대각 벽의 비중복 폴리곤 메시, 텍스처 밉맵을 병행했다.

## 미검증 및 한계

- 실제 다른 PC/LAN/WAN, 운영 NAS/ARM64, 긴 32인 경기, 저사양 GPU·다양한 DPI·실제 다중 모니터 하드웨어 조합은 별도 검증 필요.
- 경쟁전 승률/무기 선택률/스폰 사망률은 사람 플레이테스트 필요. 고정 표적/경로 검사는 이를 대신하지 않는다.
- 모션은 절차적 포즈·GPU 스키닝·관절 스프링/래그돌이며 모션캡처/수작업 AAA 품질 평가 완료가 아니다. 살아 있는 관절은 월드와 충돌하지 않는 시각 보조이고 서버 이동은 캡슐 기반이다.
- Compatibility 종료 시 Font/텍스처 정리 순서로 추정되는 349524 bytes GL texture leak 경고가 일부 런에 남는다. 원인 확정/완전 해결이라고 표현하지 않는다. 게임 중 스크립트 오류와 구분한다.
- Docker 기능은 실제 공개 운영 서버 주소를 제공하지 않는다. 계정/MMR/영구 제재/상대 정보 제한/행동 탐지/DDoS 운영은 후속 과제.
